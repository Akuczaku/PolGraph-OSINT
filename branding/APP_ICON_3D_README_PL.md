# Ikona aplikacji 3D

Ta wersja przygotowuje miejsce na własną ikonę 3D aplikacji.

## Zalecany motyw
- graf powiązań / sieć relacji,
- lupa analityczna,
- węzły i linie połączeń,
- nowoczesny wygląd 3D,
- niebiesko-cyjanowo-granatowa paleta,
- subtelny polski akcent.

## Pliki do podmiany
- `branding/icon_3d.png` — główny podgląd,
- `branding/icon_3d.ico` — ikona EXE i skrótu,
- `branding/icon_3d_prompt.txt` — prompt opisowy.
