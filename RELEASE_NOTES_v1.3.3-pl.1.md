# PolGraph OSINT 1.3.3-pl.1

Pierwsza paczka przygotowana do publicznej publikacji forka.

## Najważniejsze funkcje
- kompletna polska lokalizacja GUI;
- wbudowany polski manual;
- opcjonalny profil Polski OSINT;
- PESEL / NIP / REGON / IBAN PL;
- skróty do polskich rejestrów;
- panel „Moje bazy”;
- import CSV / JSON / Graph JSON;
- helper SQLite;
- zachowywanie źródła rekordów przez `source_db`.

## Zmiany publikacyjne
- nowa nazwa **PolGraph OSINT**;
- nowe, niezależne logo i ikona;
- zachowana pełna atrybucja autora oryginału;
- zachowane `LICENSE`, `NOTICE`, `THIRD-PARTY-NOTICES.md`;
- usunięta robocza baza `data/osintgraph.db`;
- dodane CI, dokumentacja GitHub i instrukcja GitHub Desktop.
