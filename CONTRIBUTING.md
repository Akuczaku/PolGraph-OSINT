# Contributing

Contributions are welcome.

## Before opening a pull request

- do not include real OSINT case data or personal data;
- do not include API keys or private configuration;
- keep original upstream attribution and legal files;
- keep the public fork name/logo distinct from the upstream project;
- run `python scripts/check_repo.py`;
- verify Polish and English UI after changing i18n keys.
